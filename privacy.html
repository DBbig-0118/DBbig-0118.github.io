디비빅SQL 개인정보처리방침

시행일: 2026년 11월 17일

디비빅SQL(이하 "앱")은 Oracle 데이터베이스 학습과 SQL 문제풀이를 위한 개인 학습 앱입니다. 앱은 회원가입이나 로그인 없이 동작하며, 이용자의 개인정보를 수집하거나 개발자의 서버로 전송하지 않습니다.

1. 수집하는 정보

앱은 이름, 이메일, 전화번호, 위치, 기기 식별자 등 개인을 식별할 수 있는 정보를 수집하지 않습니다.

2. 기기에 저장되는 정보

학습 기능을 위해 아래 정보가 이용자 기기의 브라우저 저장소(localStorage, 캐시)에만 저장됩니다. 이 정보는 개발자를 포함한 외부로 전송되지 않습니다.

항목용도
레슨 완료 여부, 퀴즈 결과·오답 노트, SQL 문제 풀이 기록, 학습 일자진도 표시, 복습 기능
작성 중인 SQL 초안다시 열었을 때 이어서 작성
화면 테마, 글자 크기, 하루 목표, 읽기 속도앱 설정 유지
앱 파일(HTML·스크립트·아이콘)오프라인 실행

이용자는 앱의 ⚙️ 설정 → "초기화" 또는 기기의 앱 삭제·사이트 데이터 삭제로 언제든 이 정보를 지울 수 있습니다. "백업 복사" 기능은 이용자가 직접 복사한 경우에만 클립보드로 내용을 내보냅니다.

3. 외부 서비스

  • GitHub Pages: 앱 파일을 내려받는 호스팅입니다. 접속 시 GitHub이 일반적인 웹 서버 로그(IP 주소 등)를 처리할 수 있으며, 이는 GitHub 개인정보 처리방침을 따릅니다.
  • Google Fonts: 글꼴을 내려받을 때 Google 서버에 접속합니다(Google 개인정보처리방침).
  • jsDelivr: 기기에 저장된 SQL 엔진 파일을 쓸 수 없을 때만 예비로 접속합니다.
  • 듣기 기능: 기기에 내장된 음성 합성 기능을 사용합니다. 음성 엔진에 따라 읽을 학습 텍스트가 해당 엔진 제공자에서 처리될 수 있습니다. 학습 내용 외의 정보는 전달하지 않습니다.

앱에는 광고, 분석(통계) 도구, 추적 쿠키가 없습니다.

4. 아동의 개인정보

앱은 개인정보를 수집하지 않으므로 만 14세 미만 아동의 개인정보도 수집하지 않습니다.
